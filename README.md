# Boss直聘自动化投递Skill

让 Agent 代替人工完成 Boss直聘 的岗位筛选、打招呼和投递。

这个项目的重点不是“多投几个岗位”，而是把人工反复做的这些动作交给 Agent：

- 先按你的偏好筛岗位
- 再对符合条件的岗位打招呼
- 再对已回复且仍然符合偏好的对话发送简历

## 它能做什么

- 先问清楚你的投递偏好
- 按偏好筛掉不想投的岗位、方向、行业和公司
- 优先在同一列表页里完成岗位查看、筛选和打招呼
- 对符合条件的岗位完成打招呼
- 进入消息页继续跟进已回复对话
- 对仍然符合偏好的对话发送简历

## 适合谁

- 想让 Agent 代替自己做 Boss直聘 岗位筛选的人
- 想把 Boss直聘 上重复的打招呼和投递动作交给 Agent 的人
- 想把自己的投递偏好沉淀成固定说明的人

## 仓库内容

```text
.
├── README.md
```

- `SKILL.md`：智能体执行这类任务时要遵循的流程说明
- `preferences.example.md`：用户偏好示例

## 如何接入

### 方式一：你的 Agent 支持 Skill 目录

把当前仓库内容复制到宿主的 skill 目录下，并把目录命名为：

```text
apply-boss-jobs
```

例如：

```text
<host-skills-dir>/apply-boss-jobs/
```

只要宿主会读取这个目录里的 `SKILL.md`，就可以使用这个 skill。

### 方式二：你的 Agent 不支持 Skill 目录

直接把下面两份内容交给智能体：

1. `SKILL.md`
2. 你填写好的偏好说明，或者你直接在对话里写出的偏好

## 如何使用

推荐顺序：

1. 先给智能体一份偏好说明，或者让它先问清楚偏好
2. 让它查看当前 Boss 页面
3. 让它解释哪些岗位符合偏好、哪些岗位跳过
4. 对符合条件的岗位完成打招呼
5. 进入消息页
6. 对已回复且仍然符合偏好的对话发送简历

## 示例指令

```text
使用 $apply-boss-jobs。先问我缺失的偏好，再查看当前 Boss 页面，解释哪些岗位符合偏好、哪些岗位跳过。然后代替我完成打招呼，并在消息页里对已回复且仍然符合偏好的对话发送简历。
```

## 偏好说明怎么写

参考：

`preferences.example.md`

常见偏好包括：

- 浏览器
- 本地简历
- 求职类型
- 目标城市
- 目标岗位
- 行业或公司类型
- 排除方向
- 排除岗位或项目类型
- 排除行业或公司类型
- 排除公司
- 投递策略
- 其他补充说明

## 使用边界

- 这个仓库提供的是工作流说明
- 浏览器操作能力由宿主决定
- 适合用于正常求职流程中的岗位筛选、打招呼和投递
